# 報名表後端（Google Apps Script）

報名資料會寫進一份 Google 試算表，並（可選）寄確認信給報名者。

## 設定步驟

1. 開一份新的 **Google 試算表**（例如命名「116 PGY 說明會報名」）。
2. 上方選單 **擴充功能 → Apps Script**。
3. 刪掉預設內容，把本資料夾的 `Code.gs` 全部貼上，按儲存。
4. 上方函式選單選 `setup`，按 **執行**，依畫面完成 Google 帳號授權。
   試算表會出現「報名資料」工作表與欄位標題。
5. 右上角 **部署 → 新增部署作業**：
   - 類型：**網頁應用程式**
   - 執行身分：**我**
   - 誰可以存取：**所有人**
6. 按「部署」，複製 **網頁應用程式網址**（結尾是 `/exec`）。
7. 打開網站的 `assets/js/main.js`，把網址貼到最上方：
   ```js
   var GAS_URL = 'https://script.google.com/macros/s/xxxxxxxx/exec';
   ```
8. 存檔並推上 GitHub，網站的報名表就能使用了。

## 可調整的設定（`Code.gs` 最上方）

| 設定 | 說明 |
| --- | --- |
| `SEND_CONFIRMATION` | 預設 `false`（不寄信）；改為 `true` 時，報名成功會寄確認信給報名者 |
| `REG_DEADLINE` | 報名截止時間（預設 115/11/14 00:00，即 11/13 當天都可報名）；之後送出的報名一律擋下。網站 `assets/js/main.js` 的 `REG_DEADLINE` 要設成同一時間 |
| `NOTIFY_EMAIL` | 填入承辦人信箱，每有新報名就寄通知；留空則不寄 |
| `SHEET_NAME` | 資料寫入的工作表名稱 |

## 修改 Code.gs 之後

要到 **部署 → 管理部署作業 → 編輯（鉛筆）→ 版本選「新版本」→ 部署**，
網址不變，改動才會生效。若是「新增部署作業」會產生新網址，需要再更新 `GAS_URL`。

## 報名狀況儀表板

網站的 `/yunDDDashhhboardd4240/` 是報名狀況儀表板，需輸入密碼才能看到資料。

1. Apps Script 編輯器左側 **專案設定（齒輪）→ 指令碼屬性 → 新增指令碼屬性**
   - 屬性：`DASHBOARD_KEY`
   - 值：自訂一組密碼（建議 12 字以上）
2. 更新 `Code.gs` 後，**部署 → 管理部署作業 → 編輯 → 版本選「新版本」→ 部署**（網址不變）。
3. 打開儀表板網址，輸入上面設定的密碼即可。

> 密碼只存在 Google 端，不在 GitHub 上。要換密碼，直接改 `DASHBOARD_KEY` 的值即可，不用重新部署。

## 網頁瀏覽人次

網站右下角會顯示「瀏覽人次」，計數存在 **專案設定 → 指令碼屬性** 的 `VIEW_COUNT`（第一次有人瀏覽時自動建立）。

- 同一個瀏覽器分頁重新整理不會重複計算。
- 網址加上 `?nocount`（例如 `.../?nocount`）只看數字、不會加一。
- 要歸零或調整數字，直接修改 `VIEW_COUNT` 的值即可。
- 後端尚未更新（舊版 `Code.gs`）時，右下角不會出現計數，頁面其他功能不受影響。

## 現場報到

網站的 `/checkinnnnn/` 是說明會當天的報到（簽到）頁面。與會者用手機開啟，輸入報名時的**姓名**，
系統從「報名資料」工作表找到資料後按「確認報到」，報到時間會寫入 **J 欄「報到時間」**。

- 姓名需與報名時**一模一樣**才查得到（只忽略前後空白）；查到後顯示本人資料，按「確認報到」即可。同名時會列出學校、學制與遮蔽後的 Email 讓本人選擇。
- 已報到的人再按一次不會覆蓋原本的報到時間。
- **簽退＋滿意度**：簽退是另一個頁面 `/checkouttt/`（現場另做一張簽退 QR Code）。單頁設計：最上方「填寫人（必填）」輸入姓名，
  系統自動帶出本人資料，往下滑直接填問卷。滿意度共 11 題、每題必填：第 1～7 題 1～5 分、第 8～10 題詳答、第 11 題甄試參加意願（單選），
  按「送出並簽退」才會完成簽退。未報到的人無法簽退。
  滿意度寫入**第三頁「滿意度調查」工作表**，簽退時間寫入「報名資料」K 欄與「報到系統」。
  要改題目：`checkouttt/index.html` 的 `SURVEY` 與 `Code.gs` 的 `SURVEY` 要一起改、題數與順序相同。
- 每完成一筆報到，會在**第二頁「報到系統」工作表**新增一列：【姓名、電子郵件、就讀學校、學制、報到時間、簽退時間】，
  簽退時會填上同一列的簽退時間。這個工作表第一次有人報到時會自動建立（也可以手動執行一次 `setup`）；重複報到不會重複寫入。
- 報到不限時段，隨時都可以查詢與報到。事前測試後，記得刪掉 J 欄測試留下的報到時間。
- 儀表板會多「報到」「簽退」兩欄，第四張卡片在說明會當天（或有人報到後）改顯示「已報到人數／報到率」；
  搜尋框輸入「已報到」「未報到」「已簽退」「未簽退」可篩選名單，下載的 Excel 也會包含報到與簽退時間。

### 報到代碼（建議設定，防止不在現場的人遠端報到）

1. **專案設定 → 指令碼屬性** 新增 `CHECKIN_CODE`，值自訂（例如 `pgy1129`）。
2. 現場 QR Code 的網址加上代碼：`https://<網站網址>/checkinnnnn/?c=pgy1129`、`https://<網站網址>/checkouttt/?c=pgy1129`
   掃碼進入的人不用手動輸入代碼；沒有代碼的人頁面會要求輸入。
3. 不設定 `CHECKIN_CODE` 就不檢查代碼。

### 更新步驟

更新 `Code.gs` 後一樣要 **部署 → 管理部署作業 → 編輯 → 版本選「新版本」→ 部署**（網址不變）。

## 簽退頁快速查詢（Google Sheets 發布的 CSV）

簽到頁 `/checkinnnnn/` 與簽退頁 `/checkouttt/` 都會先讀「發布到網路」的 CSV 查姓名，幾乎不用等待；CSV 查不到（簽退頁另含顯示尚未報到）時，會自動改向 GAS 即時確認。報到與簽退一律由 GAS 驗證並寫入。

1. 更新 `Code.gs` 後，在 Apps Script 上方函式選單選 **`setupLookupSheet`** → 執行。
   試算表會多一張「**查詢名單**」工作表（公式自動同步「報名資料」，Email 已遮蔽，不需手動維護）。
2. 試算表 **檔案 → 共用 → 發布到網路**：
   - 連結：選「**查詢名單**」（不要選「整份文件」）
   - 格式：**逗號分隔值 (.csv)**
   - 按「發布」，複製網址
3. 把網址貼到 `checkinnnnn/index.html` 與 `checkouttt/index.html` 的 `CSV_URL`（或交給 Claude 處理）。

注意：
- 發布後，**任何拿到網址的人都能下載「查詢名單」**（姓名、遮蔽後 Email、學校、學制、報到／簽退時間）。活動結束後請到「發布到網路」按「**停止發布**」。
- Google 發布的 CSV 約有數分鐘延遲，所以剛報到的人可能要等 GAS 即時確認（約 1～3 秒），不影響正確性。
- `CSV_URL` 留空時，該頁會全部改用 GAS 查詢，功能不受影響。

## 現場抽獎

網站的 `/drawwwww/` 是說明會現場的抽獎頁（扭蛋機動畫），建議用電腦接投影幕、按「全螢幕」使用。
畫面分三欄：左邊是「目前總報到人數」「13:30 前報到人數」與中獎名單，中間是扭蛋機，右邊是抽籤規則與獎品。

- 登入密碼與儀表板相同（`DASHBOARD_KEY`），名單直接讀取「報名資料」；不需要修改 `Code.gs`。
- **抽獎資格：11/29（日）13:30 前報到的人**（J 欄報到時間早於 13:30）。截止時間在 `drawwwww/index.html` 的 `CUTOFF`。
- 右側點選獎品（iPad Wi-Fi 機型 128GB、Apple Watch SE 3、AirPods 5）設定這一輪的獎項，會一起記在中獎名單上；再點一次可取消。
- 按「開始抽獎」或鍵盤**空白鍵**：扭蛋機轉動 → 掉出扭蛋 → 打開顯示中獎者姓名、學校、學制。
- 已中獎者不會再被抽到；按「不在現場，重抽」會把該名標記為不在現場並自動重抽。
- 名單每分鐘自動更新（新報到的人會自動加入）；要立即更新可重新整理頁面。
- **音樂與音效**：待機時一直播放輕快的背景音樂；轉動時有把手棘輪、扭蛋碰撞、小鼓滾奏聲（背景音樂自動調小），開獎時有開蓋聲＋號角＋鈸。
  全部由瀏覽器即時合成，不需要音檔。瀏覽器規定要先點一下畫面才能出聲，重新整理後右上角會提示「點一下畫面開始播放音樂」。
  右上角「🎵 音樂」「🔊 音效」可分別開關（會記住設定）。投影前記得確認電腦接上喇叭、音量已打開。
- 中獎名單存在**這台電腦的瀏覽器**中，重新整理不會消失；要重來請按「清空」。名單上的 × 可把人移除並放回抽獎池。
